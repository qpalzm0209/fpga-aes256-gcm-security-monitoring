# 26-08-13_Jetson Bridge 현재 구성

## 역할

Jetson Orin Nano는 Zybo TX와 RX 사이의 투명 L2 중간 노드다. 영상 packet은 Linux kernel bridge `br-video`를 통과한다. Dashboard backend는 같은 경로의 packet과 NIC counter를 관찰하고 공격 엔진을 제어한다.

## 네트워크

| 항목 | 값 |
|---|---|
| TX video IP | `10.10.15.2/24` |
| RX video IP | `10.10.15.3/24` |
| video UDP port | `5602` |
| packet payload | AAD 16 B + ciphertext 1440 B + TAG 16 B |
| Jetson bridge | `br-video` |
| Dashboard | `0.0.0.0:4173` |
| Local VLM app/API | `127.0.0.1:4188` |
| llama.cpp model server | `127.0.0.1:4190` |

`br-video`의 물리 member는 `/sys/class/net/br-video/brif`에서 런타임에 확인한다. 설정 스크립트는 연결된 물리 Ethernet NIC가 정확히 두 개이면 자동 선택한다. NIC가 더 많으면 TX 측과 RX 측 인터페이스를 인자로 지정한다.

Dashboard backend의 ingress 기본값은 `eno1`이며 `--stream-interface`로 변경할 수 있다. egress는 현재 bridge member에서 ingress를 제외한 interface로 선택한다. Tamper 준비 스크립트의 ingress 기본값은 `eno1`이고 `BRIDGE_PORT` 환경 변수로 지정할 수 있다.

## Page 01 packet monitoring

UDP 5602의 PCAM packet을 관찰해 session ID, frame ID, packet ID, ciphertext entropy, byte distribution, serial correlation, packet rate, packet timing jitter를 계산한다.

throughput은 bridge 물리 member의 L2 byte counter에서 구한다. 화면의 주값과 graph는 egress OUT이며 ingress IN은 보조값으로 표시한다. NIC drop은 최근 30초 증가량과 cumulative total을 함께 표시한다. frontend는 backend snapshot을 200 ms 주기로 읽는다.

## Page 02 공격

Tamper는 Jetson의 packet 경로에서 ciphertext bit를 변경하고 packet TAG를 유지한다. Replay는 정상 암호 packet을 저장한 뒤 live flow에 재주입한다. RX의 GCM 인증 결과와 5종 detector event는 RX UART를 통해 PC Dashboard에 표시된다.

## Page 03 Weak-Key와 VLM

Jetson은 TX에 Weak Session 생성을 요청하고 관찰한 AES-GCM packet으로 CPU 또는 CUDA key search를 수행한다. TAG 검증을 통과한 key로 recovered frame을 만든다. 사용자가 분석 버튼을 누르면 NVIDIA Cosmos-Reason2-2B Q4_K_M 모델이 recovered frame을 Jetson 로컬에서 분석한다.
